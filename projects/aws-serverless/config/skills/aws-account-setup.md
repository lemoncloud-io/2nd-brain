# AWS Account Setup (조직 명의 계정 가입 · 가입 직후 7가지)

> 개념: [AWS IAM](../../../../wiki/aws-iam.md) · [서버리스 데이터 파이프라인](../../../../wiki/serverless-data-pipeline.md) — 이 스킬은 절차만 다룬다.

계정 소유권은 쓰는 쪽(조직 또는 본인)에 있어야 한다 — 데이터·비용·사용 종료 후 운영 모두 그쪽 것이다. 그래서 계정은 반드시
**조직(또는 본인) 명의**로 계정 관리자가 직접 만들고, 배포 작업자(사람이든 에이전트든)가 다른 명의로 대신 만들지 않는다.
계정 관리자는 1부 안내서(`../../guides/01-aws-account-setup.md`)를 따라 가입하고, 끝나면 `aws-iam-access` 로 배포 키를 발급한다.
가입 자체는 15~20분, 활성화는 수 분~최대 24시간.

## 결정값 (1부 안내서와 같은 값)

| 항목 | 값 | 이유 |
|---|---|---|
| 계정 명의 | 조직(또는 본인) | 소유권 |
| 플랜 | **Paid(유료)** | 2025-07-15 이후 신규 가입은 Free/Paid 택일. Free 는 6개월 종료·서비스 제한(OpenSearch Serverless 가용 여부 `미검증`) |
| 지원 플랜 | 화면 "기본 지원 - 무료" | 유료 플랜(화면 "비즈니스 지원+", 월 USD 29~)은 필요 없음 |
| 리전 | ap-northeast-2(서울) | 배포 키 정책이 다른 리전을 막는다 |
| 루트 이메일 | 조직 공용 메일(새로 만들어도 됨) | 담당자 퇴사 대비. 이미 AWS 에 쓴 메일은 불가 |
| 결제 | 법인 **신용**카드, 해외 결제 허용 | 체크카드·해외 차단은 실패 1순위 |
| 세금 | 사업자등록번호 + 사업자등록증 파일 | 세금계산서 발행 조건. 편집 폼에 "세금 등록 증명서" 업로드 칸이 있다(`18-tax-settings-form.png`) |

## 준비물 체크리스트 (1부 안내서 § 1 준비물)

- [ ] 조직 공용 이메일 + 그 메일함을 열어 둘 것(인증 코드)
- [ ] 법인 신용카드(번호·유효기간·CVC). 화면 문구 "1 USD 를 3~5일간 예치하여 계정을 인증"(실측 09-23) — 인증용 예치
- [ ] 조직 주소(국가를 대한민국으로 고르면 한글 입력 — 실측 09-23)
- [ ] 계정 관리자 휴대폰(연락처 +82 입력용. 문자 PIN 단계는 09-23 화면에 없었다)
- [ ] 사업자등록번호 + 사업자등록증 PDF/이미지(세금 설정 폼에서 업로드, 5 MB 이하)
- [ ] 스마트폰 인증 앱(Google/Microsoft Authenticator)
- [ ] 화면을 공유·녹화하거나 에이전트에게 보여 주는 중이면 — 카드 번호·루트 암호·비밀 액세스 키를 입력하는 동안은 멈춘다
- [ ] 정책 JSON(`../policies/` 6개 — 2부 배포 키 발급용 3개, 3부 실무자 권한용 3개) — 각 부의 발급 단계에서 붙여넣는다
- [ ] 배포 작업자 알림 메일 주소(계정 관리자와 다른 사람이고 받고 싶을 때) — 예산 알림 수신자(4번)에 추가

## 가입 단계 (콘솔 순서, 8화면)

가입(이메일·계정 이름) → 이메일 코드 → 암호(1/5, 흔한 암호는 유출 DB 대조로 거부) → **유료 플랜 선택** → 연락처(2/5: 이름·조직명·**+82** 전화·국가 대한민국·한글 주소·약관 체크) →
결제 정보(3/5: 법인카드 → 「확인」 → 새 창에서 카드사 인증(3DS)) → 지원 플랜 **기본 지원 - 무료**(5/5) → 완료. 실측 09-23: "개인용/비즈니스" 선택과 문자 PIN 본인 확인 단계는 **없었다**(카드 인증이 대체).
단계 순서·화면 문구는 AWS 가 바꾼다 — 1부 안내서의 스크린샷 날짜를 확인하고, 다르면 화면 기준으로 간다.

## 가입 직후 7가지 (1~4 루트, 5 부터 관리자 사용자, 이 순서로, 약 25분)

1. **루트 MFA** — 우측 상단 계정 → 보안 자격 증명 → MFA 할당 → 기본 선택 "패스키 또는 보안 키" 를 **인증 관리자 앱**으로 바꾼다. 가능하면 두 번째 기기도. 루트 액세스 키는 **만들지 않는다**.
2. **세금 설정** — 과금 정보 및 비용 관리 → 세금 설정 → 편집 → 대한민국 · VAT 이메일 주소(경리 메일) · 세금 등록 번호(사업자등록번호, `123-45-67890` 형식) · 세금 등록 증명서(사업자등록증 파일 선택) · 법인명·대표자·업태·종목 · 법인 주소. 청구서 명의가 여기서 정해진다.
3. **결제 설정** — 과금 정보 및 비용 관리 → 왼쪽 **결제 기본 설정**: 기본 결제 수단 = 법인카드 확인, 통화 USD 유지. **빌링 기본 설정**: PDF 인보이스 메일 수신(경리 메일 추가).
   **계정 → "결제 정보에 대한 IAM 사용자 및 역할 액세스" → 편집 → 활성화** — 꺼져 있으면 관리자 IAM 사용자가 결제 콘솔을 못 본다. 루트를 봉인하려면 필수. (Budgets API 는 이 스위치와 무관하게 읽힌다 — 실측 09-23.)
   **Cost Explorer 첫 진입** — 과금 정보 및 비용 관리 → Cost Explorer 를 한 번 연다. 안 열면 배포 키의 `ce:` 호출이 `User not enabled for cost explorer access` 로 실패한다. 데이터는 24시간 뒤 — 배포 키 발급을 기다리게 하지는 않는다(`verify.sh` V3d 는 정책 시뮬레이션이라 활성화와 무관하고, 시뮬레이션이 막혔을 때만 실호출 1건을 쓴다). `ce:` API 는 요청당 USD 0.01(09-27 실측 `USE1-APIRequest` 5건 USD 0.05).
4. **예산 알림(Budgets)** — `sls-monthly` 월 USD 50(실제 50%·80%, 예측 100% 알림) + `sls-zero-guard` 월 USD 1(무슨 비용이든 나면 알림). 수신자 = 계정 관리자(+ 배포 작업자가 따로 있고 받고 싶으면 그 주소). zero-guard 는 배포 작업자의 비용 조회(요청당 USD 0.01)·OpenSearch 로 **첫 달에 곧 울린다 — 예상된 알림**이라고 수신자에게 미리 말해 둔다. 데이터 반영 최대 24시간. 예산은 알림만 — DynamoDB 프로비저닝 용량·Lambda 실행량은 키 정책이 못 막는 비용이라 이 알림이 유일한 방어다.
5. **관리자 IAM 사용자** — IAM → 사용자 생성 `admin-<영문이름>`(예 `admin-hong` — 한글 불가, 영문·숫자·`+=,.@_-`만) → 콘솔 액세스 → `AdministratorAccess` 직접 연결 → MFA 등록. 이후 루트는 쓰지 않는다(루트가 필요한 일: 결제 수단 변경·지원 플랜 변경·계정 폐쇄 — `../../guides/01-aws-account-setup.md` § 3.5 와 같은 목록). 이 사용자의 ARN(IAM → 사용자 → 요약의 `arn:aws:iam::…:user/admin-…`)을 적어 둔다 — stack2 `QueryPrincipalArns`(대시보드 접근)에 넣는다.
   **5번부터는 이 관리자 사용자로 로그인해서 한다**(루트는 여기서 로그아웃). 6·7번과 키 발급 모두.
6. **OpenSearch Serverless 용량 상한** — 우측 상단 리전이 **아시아 태평양(서울)** 인지 먼저 본다(용량 상한은 리전별 설정). OpenSearch → Serverless → Dashboard → 용량 관리 → 구성 → 최대 인덱싱/검색 OCU 를 **2**(용량 **상한**으로 고를 수 있는 최솟값, 기본 10 — 09-24 실측)로. 이 상한과 과금 최소 단위(복제본 끄면 1 OCU)는 다른 값이다 — `aws-opensearch.md § 비용`. 배포 키는 `aoss:UpdateAccountSettings` 가 거부라 계정 관리자만 바꿀 수 있다.
7. **S3 계정 수준 퍼블릭 액세스 차단** — S3 → 왼쪽 **계정 및 조직 설정** → "이 계정의 퍼블릭 액세스 차단 설정" → 편집 → 모든 퍼블릭 액세스 차단 → 확인 입력. 신규 계정은 설정 자체가 없다(09-24 실측 `NoSuchPublicAccessBlockConfiguration`). 배포 키는 버킷 정책은 쓸 수 있지만 이 계정 설정은 못 끈다 — 버킷 공개를 막는 유일한 문. verify V9 가 본다.

끝나면 `aws-iam-access.md § 절차 A` — 배포 키 발급(관리자 사용자로). 사용이 끝날 때는 `aws-iam-access.md § 사용 종료·정리`.

## 검증 (배포 키를 프로파일로 등록한 뒤 `verify.sh` V9, 또는 관리자 사용자의 콘솔 화면으로)

| 확인 | 기대 |
|---|---|
| `aws iam get-account-summary` → `AccountMFAEnabled` | 1 (루트 MFA) |
| 같은 출력 `AccountAccessKeysPresent` | 0 (루트 키 없음) |
| Budgets 콘솔 | 예산 2개, 수신자 1명 이상(배포 작업자를 추가했으면 2명) |
| 세금 설정 | 상태 "확인됨", 사업자등록번호 표시 |
| OpenSearch 용량 관리 | 최대 인덱싱·검색 OCU = 2 |
| S3 계정 퍼블릭 액세스 차단 | 4개 모두 켜짐 (`aws s3control get-public-access-block`) |
| IAM 사용자 목록 | `admin-<이름>`(MFA) + `sls-deployer`(콘솔 없음) |

## 자주 막히는 곳

| 증상 | 원인 | 조치 |
|---|---|---|
| 카드 입력 뒤 「확인」 → "카드 발급자에 연결 중"·"확인 중" 에서 멈춤 | 카드사 인증(3DS) 창이 **새 창·새 탭**으로 열렸는데 안 보임, 또는 팝업 차단 | 다른 탭·창을 찾는다 → 브라우저 팝업 허용 → 카드사 앱 푸시 승인 → 2~3분 뒤에도 그대로면 창을 닫고 결제 단계부터 다시(원인 추정, `미검증`) |
| "결제 수단을 확인할 수 없음" | 체크카드 · 해외 결제 차단 · 명의/주소 불일치 | 법인 신용카드, 카드사 앱에서 해외 결제 허용, 청구지 주소가 연락처 주소와 같은지(한글 그대로) |
| 문자 PIN 화면이 나왔는데 안 옴 | 대표번호 ARS · 통신사 차단 | 음성 통화로, 계정 관리자 휴대폰으로 (09-23 화면엔 이 단계 없음) |
| 24시간 지나도 활성화 안 됨 | 카드 사전 승인 실패 · 정보 불일치 | 결제 기본 설정의 카드 상태 → AWS Support(무료 지원도 계정·결제 문의 가능) |
| 이메일 이미 사용 중 | 과거 가입 | 다른 공용 메일, 또는 기존 계정 루트 비밀번호 재설정 |
| 세금계산서 안 나옴 | 세금 설정 미등록 · 정보 불일치 | 2번 재확인. 등록 전 청구분 소급 여부 `미검증` |
| 관리자 IAM 사용자로 결제 화면이 안 보임 | 3번의 결제 정보 액세스 스위치 꺼짐 | 루트로 켠다 |
| 배포 키 `ce:` AccessDenied "not enabled for cost explorer" | Cost Explorer 미활성화 | 3번의 Cost Explorer 첫 진입, 24시간 |
| 예산 알림 안 옴 | 반영 24시간 · 수신자 오타 | 하루 뒤 확인 |

## 무엇이 만들어지나 (계정 관리자용 한 문단)

이 계정에는 파일 보관소(S3), 파일이 들어오면 자동으로 도는 작은 프로그램(Lambda), 정리된 행을
쌓는 표(DynamoDB), 검색·집계 엔진(OpenSearch)이 생긴다. 서버를 사거나 켜 두는 것이 없고,
쓴 만큼 낸다. 유일한 고정비는 OpenSearch(존재만으로 시간당 과금)라 사용 기간에만 켠다.
배포 키는 이 네 가지와 그 운영 부품(로그·알람·큐·배포)만 만질 수 있고, 계정·결제·그 밖의 서비스는 명시 거부다. OpenSearch 고정비의 단가·월 상한 추정은 한곳에만 둔다 — `aws-opensearch.md § 비용`.
