# 비개발자 온보딩 가이드 — Claude에게 한 줄로 설치 맡기기
<!-- origin: lemoncloud-io/knowledge@6f4088ca:docs/non-developer-onboarding.md -->

작성일: 2026-08-24 · 개정: 2026-10-27 (Claude 데스크톱 Code 탭 경로로 교체, Obsidian 제외)
대상: 문서를 읽고·쓰고·클리핑하는 비개발자 팀원 (Tier 1)

> 개발자·자동화 담당자용 상세 가이드는 [`knowledge-wiki-setup-guide.md`](knowledge-wiki-setup-guide.md)를 본다. 이 문서는 터미널을 쓰지 않는 경로다 —
> 설치도 이후 작업도 Claude 데스크톱 앱의 **Code 탭**에서 말로 시킨다. Claude가 따라 하는 절차서는 저장소 루트의
> [`SETUP.md`](../SETUP.md)다.

## 끝나면 되는 것

- 내 GitHub 계정에 비공개 위키 저장소가 생기고(또는 팀 위키에 합류하고), 내 컴퓨터(기본 `~/knowledge`)에 내려받아진다.
- Code 탭에서 "클리핑 처리해줘"라고 하면 정리·분류·검토용 PR 생성까지 Claude가 한다.
- "볼트 뷰어 열어줘"·"연결 그래프 보여줘"로 위키를 화면과 그래프로 본다.
- git, 브랜치, 커밋, PR을 직접 다루지 않는다 — 전부 Claude가 대신한다.

## 준비물

| 항목 | 어디서 받나 |
| --- | --- |
| Claude 유료 플랜 계정 (Pro 이상 — Code 탭은 무료 플랜에서 쓸 수 없다) | 회사 좌석 또는 개인 구독 |
| Claude 데스크톱 앱 | <https://claude.ai/download> |
| GitHub 계정 (없으면 설치 중에 무료로 가입) | <https://github.com> |
| (팀 위키에 합류할 때만) 팀 위키 저장소 주소 + 초대 수락 | 팀 관리자 |

## 1단계 — Code 탭에서 한 줄 입력

1. Claude 데스크톱 앱을 열고 로그인한다.
2. 위쪽의 **Code** 탭을 누르고 **로컬 세션**을 연다(폴더는 홈 폴더 그대로 둔다).
   일반 채팅과 Cowork는 설치 명령을 실행할 수 없어 이 단계에 쓸 수 없다.
3. 아래 한 줄을 그대로 입력한다.

   ```text
   github.com/lemoncloud-io/2nd-brain 의 SETUP.md 대로 설정해줘
   ```

## 2단계 — Claude가 부탁하는 것만 하기

Claude가 순서대로 진행하면서 사람 손이 필요한 순간에만 멈춰서 부탁한다.

- **팀 위키가 있는지** — 팀 관리자에게 받은 주소가 있으면 그 주소를, 없으면 "새로 만들어줘"라고 답한다.
- **(Mac, 처음 한 번) Homebrew 설치** — Claude가 보여주는 한 줄을 Mac의 **터미널** 앱에 붙여넣는다.
  Mac 로그인 비밀번호를 묻는다(입력해도 화면에 안 보이는 게 정상). 끝나면 Claude에게 "끝났어"라고 알린다.
- **GitHub 승인** — Claude가 알려 주는 주소(<https://github.com/login/device>)를 열고, 보여주는 코드 8자리를 입력한 뒤 **Authorize**.
- **(Windows) 개발자 모드** — 요청할 때만: 설정 → 시스템 → 개발자용 → 개발자 모드 켜기.
- **권한 확인 창** — Code 탭이 명령 실행 허락을 물으면 내용을 읽고 허용한다.

마지막에 "설정이 끝났습니다"와 내 위키 주소가 나오면 성공이다.

## 3단계 — 위키 폴더에서 새 세션 열기

설치한 세션은 위키 폴더 밖에서 열렸기 때문에 위키 규칙을 모른다. 새로 연다.

1. Code 탭에서 새 세션을 연다.
2. 폴더 선택에서 설치 마지막에 안내받은 위키 폴더(기본 홈 폴더의 **`knowledge`**)를 고른다.
3. 이렇게 말해 본다.

| 하고 싶은 것 | 입력 |
| --- | --- |
| 클리핑 정리 | "클리핑 처리해줘" |
| 위키에서 찾기 | "○○에 대해 vault에서 찾아줘" |
| 위키를 화면으로 보기 | "볼트 뷰어 열어줘" |
| 문서 연결을 그래프로 보기 | "연결 그래프 보여줘" |
| 한글·워드·PDF 넣기 | "이 파일 잉게스트해줘" + 파일 경로 |
| 주간 보고 | "주간 보고" |

## 하면 안 되는 것

- **`raw/`·`archive/` 폴더의 파일을 수정·이동·삭제하지 않는다** — 원본 보존 구역이다.
- **비밀번호·토큰·개인정보·고객사 자료를 위키에 넣지 않는다** — 한 번 올라간 기록은 지워도 이력에 남는다.
- 위키 저장소를 **공개(public)로 바꾸지 않는다**.

## 문제 해결

| 증상 | 조치 |
| --- | --- |
| Claude가 "명령을 실행할 수 없다"·"Code 탭에서 다시" 라고 한다 | 일반 채팅이나 Cowork에서 입력한 것. 1단계 2번대로 Code 탭 로컬 세션에서 다시 입력한다. |
| GitHub 코드 입력 화면이 만료됐다 | Claude에게 "GitHub 로그인 다시 해줘"라고 하면 새 코드를 준다. |
| 팀 위키 주소를 줬는데 "찾을 수 없다"·"권한이 없다" | GitHub 알림 메일의 저장소 초대를 수락했는지 확인한 뒤 Claude에게 "다시 확인해줘". 계속 실패하면 팀 관리자에게 문의. |
| 새 세션에서 "클리핑 처리해줘"를 못 알아듣는다 | 세션 폴더가 위키 폴더(기본 `knowledge`)가 아닌 것. 3단계대로 새 세션을 그 폴더로 연다. |
| 중간에 멈췄다 | 같은 Code 탭 세션에 "SETUP.md 이어서 해줘"라고 한다. 설치 단계는 다시 해도 안전하다. |

해결 안 되면: 화면의 에러 문구를 **그대로 복사**해 팀 관리자나 Claude에게 붙여넣는다.

## 팀 관리자용 체크리스트 (온보딩 시켜 주는 사람)

- [ ] (팀 위키가 아직 없으면) 관리자 본인이 위 1단계를 하며 "새로 만들어줘"로 저장소를 만든다 —
  공개 템플릿을 clone하는 것이 아니라 GitHub template 생성(`gh repo create --template lemoncloud-io/2nd-brain --private`)이 정본이고,
  `SETUP.md` 6·8단계가 그것과 `team-settings.yaml` 교체를 한다. 무료 공유가 목적이면 유료 org에 만들지 않는다(좌석 비용 발생)
- [ ] 팀 위키 저장소에 신규 팀원 초대 (읽기·쓰기 권한 — 무료 플랜으로 성립)
- [ ] 팀 위키 주소를 전달 (Claude가 물을 때 답할 값)
- [ ] Claude 유료 플랜 좌석 확인
- [ ] 온보딩 후 첫 클리핑 PR이 **팀 저장소**로 열렸는지 확인 (공개 템플릿 저장소가 아닌지)
- [ ] `projects/second-brain/config/team-settings.yaml`이 팀 값으로 교체돼 있는지 확인 (저장소 최초 구축 시 1회)

터미널을 쓰는 팀원은 이 경로 대신 [`README.md`](../README.md) § 빠른 시작의 설치 스크립트를 써도 된다(Obsidian 포함).
